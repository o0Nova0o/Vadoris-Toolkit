# Vadoris Toolkit

A lightweight control app for Acer Predator laptops on Windows: power modes, fans, temperatures, keyboard lighting, battery care and GPU settings in one place, without PredatorSense or any Acer service running.

**Status:** in development. The first public release (1.0) and its source code will be published here.
